# DEE BAKES - HERO VIDEO ASSETS

This folder hosts the cinematic hero background video for DEE BAKES.

### Recommended File Specifications:
- **Filename:** `hero-shawarma.mp4`
- **Location:** `public/videos/hero-shawarma.mp4`
- **Format:** MP4 (H.264 video codec, AAC audio codec)
- **Resolution:** 1080p (1920x1080) or 4K (3840x2160)
- **Aspect Ratio:** 16:9 landscape
- **Recommended Length:** 8 to 20 seconds seamlessly loopable
- **File Size:** Under 15MB for optimal mobile loading speeds

### Behavior:
1. When `hero-shawarma.mp4` exists in this folder, the website automatically plays it on the homepage hero background in high definition, continuously looped, muted by default with an optional sound toggle.
2. If the video is loading, decoding, or not present, the website automatically displays the ultra-high resolution cinematic shawarma commercial poster (`/images/hero-shawarma-cinematic.jpg`) with a slow ambient Ken Burns camera movement.
3. You can also customize the video URL anytime directly from the **DEE BAKES STUDIO** admin dashboard under **Settings** ➔ **Hero Video URL**.
